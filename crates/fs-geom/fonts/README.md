# Fonts for sketch text

The fonts `@skText` draws with, as Onshape's sketch text does (batch 091): its outlines are these versions'.

| file | font | version | from | licence |
|---|---|---|---|---|
| OpenSans-Regular.ttf | Open Sans Regular | 1.10 | Debian's `fonts-open-sans` 1.11 | Apache-2.0 (OpenSans-COPYRIGHT, LICENSE-Apache-2.0) |
| Arimo-Regular.ttf | Arimo Regular | 1.33 | Debian's `fonts-croscore` 20201225 | OFL-1.1 (Arimo-COPYRIGHT) |

The current releases differ (Open Sans 3's "I" is 200 to 370 units, Onshape's 201 to 371 as in 1.10).
