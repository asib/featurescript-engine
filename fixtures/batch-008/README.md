# Fixture batch 008: frames, frame trims, gussets, end caps, sketch regions as sheets

16 cases:

| features | cases |
|---|---|
| sketch regions | c001: a ring with the square inside it, and a square apart: how many sheets and faces |
| `frame` | c002–c010: square tube along an L (mitred, butted both ways, coped, corners left alone) and around a rectangle; a flat bar turned 30° and mirrored; a round tube along a line and a tangent arc; trimmed to a slanted plane |
| `frameTrim` | c011–c012: a tube ending on another in ordered groups; a tube trimmed to a plane |
| `gusset` | c013–c014: triangle, chamfered rectangle |
| `endcap` | c015–c016: matching the profile, filleted rectangle |

The profiles come from build functions in `cases.fs`, each making a context with one sketch, passed as
`PartStudioData`, as an element library's profile would be. Files as in batch 002. Generated by
`node tools/fixtures/gen-batch-008.mjs`; rebuilt in Onshape on 2026-11-08 (std 3112.0) through the UI only. Every case
built.

Notes from writing the cases: build functions must be lambdas (`const f = function(configuration is map)
returns Context { ... };`), as FeatureScript doesn't let a named function be used as a value; `gusset` reads
`shouldFlipBaseSides` for triangles too; `frameTrim` in groups fails if a trim leaves two equal pieces.
