Files as in batch 002 (no STEP: everything is sheets and wires std leaves out of it). Generated by `node
tools/fixtures/gen-batch-159.mjs`; built in Onshape on 2026-11-13 (std 3112.0) through the UI only. Every case
matches, c005 and c014 since the engine builds such surfaces pole by pole on Onshape's own arc fit (batch 163).

Findings (docs/FINDINGS.md): matching a flat face next to a profile is tangent to the face's plane. With one end free
between curved profiles, Onshape's curve across is the quadratic's plus a correction blended along the profiles from
their ends: the cubic reaching the free profile along the chord less the quadratic, at each end (c005). Profiles given
as v profiles only build the same surface. A flat fill of sketch curves faces as the loop runs from the first edge
listed, even drawn half each way; one with sheets' edges in its loop faces as if sewn to the oldest sheet, whatever
the order. An extruded sheet's side edges run out from the profile, where a solid's run back from the far end.
