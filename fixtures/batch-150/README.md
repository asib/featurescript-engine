Findings (docs/FINDINGS.md): a split's edges projected normal to a cylinder run as the tool edges they came from
(`skRectangle` draws its sides rising: the arcs round the cylinder and the lines up it run so); the engine's had run
the other way. A circle drawn off a line it's held tangent to, or a line's end held on it, moves its centre,
whichever was drawn first: where lines sit now holds before where circles do in the engine's solver. Known gap: the
dimensioned circles joined by tangent lines (c008), where Onshape keeps the second line and turns the first about
its middle.
