## Compressed queries

`qCompressed(version, text, root)` decodes, after a leading `%`, one value (counts and indices hexadecimal):
`S<length>$<text>` a string, its length pieces joined by `.` (a count of characters, or `-<index>`: that string in
the string table without its last `.` piece), joined by `.`; `B<length>$<type>` then a value: the value with that
type tag, `C<index>` then a value: tagged with the string table's type name at that index; `M<count>` a map,
`A<count>` an array, `D<number>` a number, `R<index>` the value table's value again. The string table holds every
string and type name as read; the value table every string, number, map and array as completed, a tagged value in
place of the value it tags. The query's operation ids are relative to the root (c005), and name kernel operations
as `<feature>.<operation>`: `Top.planeOp`, `FeUNWBXWR3P4AUC_0.wireOp`, `FeUNWBXWR3P4AUC_0.imprint`. A region is an
`IMPRINT` face query disambiguated by `TOPOLOGY`: an edge query and a side, 1 for the region left of the edge's
direction seen from the sketch's normal, -1 for the right (c008: 80 and 120 mm² either side of a line up x = 8).

## Initial guesses

Each sketch entity's numbers (lengths in metres): a point x, y; a line its midpoint, unit direction and start and
end parameters; a circle its centre, x direction, radius and -1; an arc a circle's and its start and end angles,
counterclockwise from that x; a Bézier 1, rational, periodic, degree, count, its points, as many zeros, its weights
and parameter range; a spline through points periodic, twice the count, the points, and an open one's end
derivatives (along a [0, 1] parameter), handles' points and parameter range. The spline is the cubic through its
points at centripetal parameters with those end derivatives, so its handles are its second and second-last poles;
a closed one is periodic, at centripetal parameters round the loop.

Findings (docs/FINDINGS.md): a Part Studio's own code is run without its calls' preconditions and its functions can
be values, a Feature Studio's not; a line its guess placed is placed at its start (`evCurveDefinition`'s origin),
where a line given its ends is at its middle; each spline point and Bézier control point is a point body, a
Bézier's control polygon construction lines, an open spline's handles construction lines from its ends in a Part
Studio's sketch and points in a Feature Studio's; closed curves' wire bodies come after the open ones', and closed
edges have no vertices.
