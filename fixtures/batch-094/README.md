Files as in batch 002, but no onshape.step: no case makes a part (Onshape offers no export then). Generated by
`node tools/fixtures/gen-batch-094.mjs`; built in Onshape on 2026-11-10 (std 3112.0) through the UI only.

Findings (docs/FINDINGS.md): BLOB_DATA is a map of the blob's type (`IMAGE`, `BREP`), data id, media type and, for
an image, its size in pixels, with the document, element, version and microversion ids opaque (`BuiltIn: N`). An
image in a sketch is bounded by four construction lines as wide as the corners are apart and as tall as the image's
shape makes that, from the lower left corner, whatever the box's height. `importForeign` with the BLOB_DATA fails its
precondition (a plain map isn't `CADImportData`), an "Execution error"; `opImportForeign` with it wants a foreign id
(`INVALID_INPUT`).
